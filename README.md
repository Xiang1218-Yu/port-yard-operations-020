# HarborGrid · 港口集装箱堆场作业协同与闸口调度系统

React + Vite + TypeScript 前端，Node.js + Express + TypeScript 服务端。面向中型集装箱码头，把船期、箱务、堆场区块、闸口预约、设备作业和异常闭环放在同一套作业控制台中。

## 启动

```bash
npm install
npm run dev
```

前端默认 Vite 端口 5178，API 默认 `http://localhost:4107`。

## 业务能力

- 船舶航次、泊位窗口、计划/已完成翻箱和延误风险
- 箱号、尺寸、冷藏温度、危险品级别、海关状态、进出口/中转流向
- 堆场区块容量、堆存热度、冷藏插座、危险品隔离和设备可达性
- 闸口预约时隙、车道、OCR/称重/封志校验状态与同车冲突检测
- 岸桥、场桥、集卡、正面吊设备池和约束感知任务队列
- **作业任务依赖与去重管理**：前置/互斥/替代关系声明、同箱同航次重复计划合并、来源血缘保留、依赖环检测、前置取消断链、替代失败回退、乐观版本并发控制、可执行集合逐条推导与任务详情/审计解释
- 自动堆位推荐、冷藏/危险品约束、海关查验阻塞、任务指派审计
- React 控制台支持船期驾驶舱、闸口操作、堆场热区、设备任务与任务依赖去重操作

## 任务依赖与去重模块（`server/src/planner.ts`）

- 关系：`prerequisite`（前置）、`mutex`（互斥）、`replacement`（替代，替代失败/取消自动恢复原任务）
- 合并：只允许同箱号 + 同航次且双方均未开始的任务；被合并任务置 `merged` 并把全部来源（闸口/船期/中控/手工）并入存活任务，合并组可在存活任务开始前整组撤销
- 一致性：声明前置/替代前做依赖环检测；前置任务取消 → 后置断链阻塞；一方开始 → 互斥对方压下；已接单（assigned/executing/done）任务不可撤销、不可合并
- 并发：所有写操作携带 `expectedVersion`，过期写入返回 `409 STALE_VERSION`；设备重新指派检测同一设备的占用冲突
- 解释：`GET /api/planner/snapshot` 返回可执行集合、统计与逐条推导；`GET /api/planner/tasks/:id` 返回任务的关系、来源血缘与合并组；`GET /api/planner/audit` 返回计划审计

当前使用内存种子数据，领域服务通过 REST API 暴露，后续可接入 TOS、OCR、称重、RTG 遥测、预约配额和优化求解器。
